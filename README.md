# Sales Performance Analysis and Reporting Dashboard

A professional, enterprise-grade Sales Performance Analysis and Reporting Dashboard designed for online educational platforms. Built with Python, Streamlit, and Plotly, featuring automated data validation, robust KPI calculations, interactive filtering, and seamless Microsoft Power BI integration.

---

## 1. System Requirements
- Operating System: Windows 10 / 11 (or macOS / Linux)
- Python Version: Python 3.9 or higher installed and added to system PATH.

---
